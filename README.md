# ProfInsight

Rate my Professor, but better. Get real-time data, trends, and AI-powered recommendations on your professors at ratemyprofessor.com to optimize your educational journey. The app features web scraping capabilities to curate a stylish dashboard with analytics of student ratings and sentiment trends. Additionally, an LLM chatbot assists you by providing more information on the professor's performance. 

Built with OpenAI API, Next.JS, React JS, and deployed on Vercel.
